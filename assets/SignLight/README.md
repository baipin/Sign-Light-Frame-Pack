# SignLight

Stable Cities: Skylines II prop export for a road-sign underlight and its rear support frame.

## Contents

- `SignLight.fbx` – the only FBX to import
- `settings.json` – automatic LOD configuration

## Model data

- Approximate dimensions: `1.58 × 3.27 × 3.20 m`
- LOD0: 358 polygons, 1,276 triangles, 664 vertices
- LOD1 reference: 299 polygons, 638 triangles, 345 vertices
- LOD2 reference: 155 polygons, 254 triangles, 153 vertices
- LOD1 target: 50% triangles
- LOD2 target: 20% triangles
- Material intent: matte painted support frame and white lamp
- FBX axis: Forward `-Y`, Up `Z`
- FBX version: 7400 / FBX 2018

This is the stable single-main-FBX version. Do not rename it to `SignLight_LOD0.fbx` and do not add the older test LOD FBX files to this folder.
